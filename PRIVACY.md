# Privacy

This project is a fully client-side static HTML application. Its video processing uses the web browser's built-in decoding/encoding capabilities; file content remains on the device.

- We do not operate an upload endpoint or account database.
- There are no third-party scripts, fonts, trackers, analytics, or video requests.
- The page includes a Content Security Policy that disallows scripted network connections.
- GitHub Pages hosting may keep ordinary site-request logs according to GitHub's policies. Local-only video files are **not uploaded** to GitHub Pages.
- Browser and operating-system file selectors require user action. Exported files are saved locally.

Always review your browser's permissions when choosing a local output folder.
